# Kristiyan Kamboshev — Developer Portfolio

Personal portfolio built with React, TypeScript, Vite and Tailwind CSS. It presents my C#/.NET projects, skills, learning journey and contact links.

## Run locally

Requirements: Node.js 24+ and npm.

```bash
npm install
npm run dev
```

## Validate and build

```bash
npm run lint
npm run test
npm run build
```

## Publish to GitHub Pages

1. Create a public repository named `Kristiyan9359.github.io`.
2. Push this project to the `main` branch.
3. In repository **Settings → Pages**, choose **GitHub Actions** as the build and deployment source.
4. The workflow in `.github/workflows/deploy.yml` builds and deploys the site after a push to `main`.

The expected URL is <https://kristiyan9359.github.io/>.
